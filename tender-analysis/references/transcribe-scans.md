# 扫描件视觉转写规程

适用：招标文件/素材为图片型 PDF（无文本层）。触发点：`parse_document.py` 返回
`[解析转写待办]`（已栅格化各页 → `work/parse/<文件名>/pages/pNNN.png`，并生成
`<名>.transcript.md` 转写模板）。执行者=当前模型（宿主具备读图能力即可；无读图
能力时向用户说明，请其提供文本型 PDF/docx 或改用其他解析通道）。

## 转写契约（产物即解析 md，行号锚全流程通用）

- **逐页誊录**：把 pages/pNNN.png 上的每一行文字写入模板对应 `<!-- p:N -->`
  锚之下——行序按版面如实誊录，不合并、不概括、不改写；
- **表格**：按行誊录，格与格之间用 `｜` 分隔（不要求还原框线），表头行照誊；
  跨页表在两页各自誊录可见部分，不拼接；
- **看不清的字**：写〔？〕占位并登记澄清（编号续 CLAR-xx），不许猜；
- **空白页**：该页锚下写一行「（空白页）」；
- 模板里的「待转写」提示行誊完可留可删（归一化时剔除）；除页锚外不要新增
  其他注释行；
- 全部誊完**重跑同一条解析命令** → `[解析成功]`（识别方式
  =pdf-scanned-transcript）；每页锚下至少 1 行内容，缺页判「转写未完」。

## 质量底线

- **数字、日期、专名（公司名/人名/证号）逐页对照页图复核**后才可引用——
  转写文本是读图誊录，识别错误概率高于原生文本，关键值错一个字就是事故；
- 评分表/前附表等**关键表格目视核对**：框线归属、合并格、行序以页图为准，
  文本行核对只在页图确认后做补充；
- 转写文本**不直接当废标判据**：废标/评分相关结论必须页图复核对应数值后
  才写入登记表；
- 证据引用照 evidence-rules：档位署名 `pdf-scanned-transcript`，行号后附页码
  （锚点 `<!-- p:N -->`）。

## 成本纪律

- 页数上限默认 40（`--page-cap` 可调）：超限先停轮向用户确认成本（转写耗时
  与页数成正比），确认后再跑；
- **分批转写**：一次消息并行读 4-6 页，誊完一批再读下一批；全部誊完才重跑
  解析命令；
- **混排 PDF**（部分页有文本层）：解析器会告警列出缺失页——只对这些页单独
  转写补录（内容并入对应登记表并注明「页图补录」），其余走常规文本通道，
  不整本重转。
